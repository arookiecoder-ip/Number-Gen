# **App Name**: RandomFloatGen

## Core Features:

- Range & Precision Inputs: Input fields for specifying the minimum value, maximum value and desired precision for random number generation.
- Random Number Generator: Core logic to generate a random floating-point number between the specified minimum and maximum values, with the given precision.
- Number Display: Display the generated random number on the web page in a clear and readable format.
- Generate Button: A prominent button to trigger the generation of a new random number.

## Style Guidelines:

- Background color: Very light desaturated green (#F0FAF3) to provide a calming backdrop.
- Primary color: Moderate lime green (#32CD32) to convey precision and freshness, fitting the app's functional and requested themes.
- Accent color: A slightly darker shade of forest green (#228B22), to offer clear visual contrast without overpowering the theme, focusing the user's attention on key actions and displayed values.
- Body and headline font: 'Inter', sans-serif, known for its legibility and clean design, is perfect for clear display of both instructions/inputs and output numbers.
