# **App Name**: PrecisionRand

## Core Features:

- Parameter Input: User input fields for defining the minimum value, maximum value, and precision of the random number.
- Random Number Generation: Generates a random number based on user-defined minimum, maximum, and precision.
- Display and Copy: Display the generated random number, allow copying

## Style Guidelines:

- Primary color: Sky blue (#87CEEB) for a calm and focused user experience.
- Background color: Very light blue (#F0F8FF) for a clean interface.
- Accent color: Pale orange (#FFB347) to highlight the result display and the generation button.
- Font: 'Inter', a grotesque-style sans-serif with a modern look, suitable for both user inputs and display.
